Primer Mapeo-> un obj Java corrsponde a una tabla de base de datos Pedido.java -> mapea -> Pedidos
Anotaciones: 
    @Entity // indica que la class sera administrada por jakarta persisten API
    @Table(name = "Pedidos")// nombre de la tabla de DB
    @Id // para decir que es la primary key
    @Column(name = "pedido_id") //Asociacion con la columna 
    @SequenceGenerator(name="pedido_seq",sequenceName ="pedido_seq_db",allocationSize = 1) //generador de secuencias para la primary key
    @GeneratedValue(strategy = GenerationType.SEQUENCE,generator = "pedido_seq")// genera la secuencia
